# Brandxpere NFC Manager - Mobile Application 📱🔐

تطبيق هاتف رسمي مخصص لإدارة وبرمجة وتأمين كروت الـ NFC الذكية الخاصة بمنصة **Brandxpere SaaS**.

---

## 🌟 الميزات الرئيسية:
1. **برمجة وقفل بنقرة واحدة (One-Tap Write & Lock):**
   - كتابة رابط بروفايل العميل على الرقاقة.
   - زرع رقم سري رئيسي للأجهزة (**32-bit Hardware Write-Lock**).
   - حماية الكارت ضد التعديل أو المسح من أي تطبيق خارجي مثل **NFC Tools**.
2. **فاحص وتشخيص كروت NFC (Tag Inspector):**
   - كشف نوع الرقاقة (NTAG213, NTAG215, NTAG216).
   - التحقق من حالة القفل والأمان.
   - إمكانية فك القفل (Unlock) وإعادة تهيئة الكارت عند الحاجة.
3. **مزامنة فورية مع السحابة:**
   - ربط الكارت بحساب العميل وتحديث حالته تلقائياً إلى `ACTIVE` في المنصة.

---

## 🚀 كيفية تشغيل وتجربة التطبيق على هاتف أندرويد:

### المتطلبات:
- تثبيت تطبيق **Expo Go** من متجر Google Play على الهاتف.
- تشغيل خادم التطبيق على جهاز الكمبيوتر:

```bash
cd apps/brandxpere-nfc-mobile
npm install
npx expo start
```

ثم امسح رمز الـ QR الظاهر على شاشة الكمبيوتر بكاميرا الهاتف (داخل تطبيق Expo Go).

---

## 📦 استخراج ملف APK جاهز للتثبيت المباشر على الهاتف:
يمكنكم تصدير ملف `APK` بضغطة واحدة باستخدام أداة EAS Build السحابية المجانية:

```bash
npm install -g eas-cli
eas login
eas build -p android --profile preview
```
ستحصلون على رابط تحميل مباشر لملف الـ APK لتثبيته على أي هاتف أندرويد خاص بالإدارة.
